Explanation & Dry Run

Depth-First Search traverses down a path until it reaches an unvisited node or dead end, then backtracks to explore remaining branches.

Dry Run Example

Start at 1 → visit neighbor 2 → visit neighbor 4. Backtrack to 2 → backtrack to 1 → visit neighbor 3. Visited sequence: 1, 2, 4, 3.

Complexity Analysis

  • Time Complexity: O(V + E) where V is vertices and E is edges.
  • Space Complexity: O(V) due to call stack depth.

Real-World Applications

  • Solving mazes and puzzle states.
  • Topological sorting and connected components analysis.
  • Cycle detection in dependency graphs.

Code Implementations (C, C++, Java)

#include <stdio.h>

void dfs(int node, int adj[][10], int deg[], int vis[]) {
    vis[node] = 1;
    printf("%d ", node);
    for (int i = 0; i < deg[node]; i++) {
        int neighbor = adj[node][i];
        if (!vis[neighbor]) dfs(neighbor, adj, deg, vis);
    }
}
#include <iostream>
#include <vector>

void dfs(int node, std::vector<int> adj[], std::vector<int>& vis, std::vector<int>& ls) {
    vis[node] = 1;
    ls.push_back(node);
    for(auto it: adj[node]) {
        if(!vis[it]) dfs(it, adj, vis, ls);
    }
}
import java.util.*;

public class DFS {
    public void dfs(int node, boolean vis[], ArrayList<ArrayList<Integer>> adj, ArrayList<Integer> ls) {
        vis[node] = true; ls.add(node);
        for (Integer it : adj.get(node)) {
            if (!vis[it]) dfs(it, vis, adj, ls);
        }
    }
}
