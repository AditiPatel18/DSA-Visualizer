Steps

  • Push the starting node onto a stack.
  • Visit one neighbor, then continue deeper.
  • Backtrack when no new paths remain.

Complexity & Applications

Complexity

  • Time: O(V + E)
  • Space: O(V)
  • Useful for cycle detection and topology checks

Applications

  • Maze solving
  • Pathfinding in puzzles
  • Dependency and workflow analysis

Advantages & Disadvantages

Advantages

  • Low memory footprint with iterative form.
  • Great for exploring full connected areas.

Disadvantages

  • Finds paths but not shortest ones by default.
  • Can get stuck in deep branches without careful handling.
