Understanding Lower Bound

The Lower Bound algorithm finds the smallest index i in a sorted array such that arr[i] ≥ target. If all elements in the array are strictly smaller than target, lower bound returns index n (size of array).

Algorithm Steps

  1. Initialize: Set low = 0, high = n - 1, and default ans = n.
  2. Calculate Mid: mid = low + (high - low) / 2.
  3. Check Condition: If arr[mid] ≥ target, set ans = mid and eliminate right half by setting high = mid - 1.
  4. Adjust Search Space: Else if arr[mid] < target, set low = mid + 1.
  5. Repeat: Continue until low > high, then return ans.

Implementation Code

#include <stdio.h>

int lowerBound(int arr[], int n, int target) {
    int low = 0, high = n - 1;
    int ans = n;

    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] >= target) {
            ans = mid;
            high = mid - 1; // Look for smaller index on the left
        } else {
            low = mid + 1;
        }
    }
    return ans;
}

int main() {
    int arr[] = {10, 20, 25, 30, 40, 50};
    int n = sizeof(arr) / sizeof(arr[0]);
    int target = 25;
    printf("Lower bound index of %d is: %d\n", target, lowerBound(arr, n, target));
    return 0;
}

public class LowerBound {
    public static int lowerBound(int[] arr, int target) {
        int low = 0, high = arr.length - 1;
        int ans = arr.length;

        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (arr[mid] >= target) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        int[] arr = {10, 20, 25, 30, 40, 50};
        int target = 25;
        System.out.println("Lower bound index: " + lowerBound(arr, target));
    }
}
