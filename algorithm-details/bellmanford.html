Steps

  • Initialize distances with the source set to zero.
  • Relax all edges repeatedly.
  • Detect negative cycles if distances keep improving.

Complexity & Applications

Complexity

  • Time: O(VE)
  • Space: O(V)
  • Works with negative edge weights

Applications

  • Financial arbitrage detection
  • Routing with negative costs
  • Constraint systems and optimization

Advantages & Disadvantages

Advantages

  • Handles negative-weight edges.
  • Simple conceptual model for shortest path relaxation.

Disadvantages

  • Slower than Dijkstra for dense graphs.
  • Less efficient for large positive-weight networks.
