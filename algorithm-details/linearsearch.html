2. Algorithm Overview

Linear Search (Sequential Search) scans array elements one by one from left to right. It requires no prerequisites (works on both sorted and unsorted data).

When to Use Linear Search?

  • When array size is small ($N \le 100$).
  • When data is unsorted and sorting overhead is undesirable.
  • When searching in single linked lists or streams.

3. Algorithm Steps & Working

  1. Start at index 0 ($i = 0$).
  2. Compare arr[i] with target.
  3. If equal, return index i immediately.
  4. Otherwise, increment i = i + 1 and repeat.
  5. If end of array is reached without a match, return -1.

4. Code Implementations

C Implementation


#include <stdio.h>

int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int main() {
    int arr[] = {10, 20, 30, 42, 50};
    int n = sizeof(arr) / sizeof(arr[0]);
    int index = linearSearch(arr, n, 42);
    if (index != -1) printf("Found at index %d\n", index);
    return 0;
}

C++ Implementation


#include <iostream>
#include <vector>
using namespace std;

int linearSearch(const vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int main() {
    vector<int> arr = {10, 20, 30, 42, 50};
    int index = linearSearch(arr, 42);
    if (index != -1) cout << "Found at index " << index << endl;
    return 0;
}

Java Implementation


public class LinearSearch {
    public static int search(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) return i;
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 42, 50};
        int index = search(arr, 42);
        System.out.println("Index: " + index);
    }
}

5. Complexity Analysis

Best Case

O(1) - Target is at index 0.

Average Case

O(N) - Target is near the middle ($N/2$ checks).

Worst Case

O(N) - Target is at last position or missing.

Space Complexity

O(1) - Constant extra space used.
