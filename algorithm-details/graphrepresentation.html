Explanation & Dry Run

An Adjacency Matrix uses a V x V 2D array where matrix[i][j] = 1 if an edge exists between vertex i and j. An Adjacency List uses an array of dynamic lists where adj[i] stores neighbor vertices connected to vertex i.

Dry Run Example

For a graph with 3 vertices (1, 2, 3) and edges (1-2, 2-3):
Adjacency List: 1: [2], 2: [1, 3], 3: [2].
Space used = 3 headers + 4 edge nodes = O(V + 2E).

Complexity Analysis

  • Adjacency Matrix: Space O(V²), Edge Lookup O(1), Neighbor Traversal O(V).
  • Adjacency List: Space O(V + 2E), Edge Lookup O(degree), Neighbor Traversal O(degree).

Real-World Applications

  • Social Network Graphs (Followers / Connections lists).
  • Routing and Map Navigation networks.
  • Web Crawler link graphs.

Code Implementations (C, C++, Java)

#include <stdio.h>
#include <stdlib.h>

struct Node { int dest; struct Node* next; };
struct Graph { int V; struct Node** adjHead; };

struct Graph* createGraph(int V) {
    struct Graph* g = (struct Graph*)malloc(sizeof(struct Graph));
    g->V = V; g->adjHead = (struct Node**)malloc(V * sizeof(struct Node*));
    for (int i = 0; i < V; i++) g->adjHead[i] = NULL;
    return g;
}
void addEdge(struct Graph* g, int u, int v) {
    struct Node* n = (struct Node*)malloc(sizeof(struct Node));
    n->dest = v; n->next = g->adjHead[u]; g->adjHead[u] = n;
}
