Merge Sort

Divide the array into halves, sort each half, and merge the results into a fully sorted array.

O(n log n)

Time

O(n)

Space

Stable

Property

Sorting

Merge sort provides predictable O(n log n) performance and is a common comparison-based sorting algorithm for larger datasets.
