Understanding Two Sum

Given a sorted array, initialize left pointer at index 0 and right pointer at index N-1. If sum < target increment left, if sum > target decrement right, returning indices when sum == target.

Implementation Code (C++)

#include <vector>

std::vector<int> twoSumSorted(std::vector<int>& arr, int target) {
    int left = 0, right = arr.size() - 1;
    while (left < right) {
        int sum = arr[left] + arr[right];
        if (sum == target) return {left, right};
        else if (sum < target) left++;
        else right--;
    }
    return {-1, -1};
}
